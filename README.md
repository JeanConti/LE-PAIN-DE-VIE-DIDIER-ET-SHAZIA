# Le Pain de Vie - Didier et Shazia

Site web de la boulangerie artisanale bio **Le Pain de Vie**, tenue par Didier et Shazia, située à Blacé (69460), Rhône.

## Présentation

Boulangerie artisanale spécialisée dans les produits bio, proposant :
- Pains au levain et pains traditionnels
- Viennoiseries dorées
- Pizzas faites maison
- Brioches et douceurs

## Stack technique

- **Frontend** : HTML5, CSS3, Bootstrap 5.3
- **Backend** : Dossier `02 backend/` (en développement)
- **Icônes** : Font Awesome 5, Bootstrap Icons
- **Polices** : Google Fonts

## Structure du projet

```

```
